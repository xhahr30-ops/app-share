현장·주소·위치·인원은 그대로 복사하고 점검예정일은 비웁니다. 새 일정 엑셀을 불러오면 같은 팀명끼리 이어집니다. 지금 회차 기록은 지워지지 않습니다.

카카오 바탕지도

키는 이 휴대폰·PC 브라우저에만 저장되고 앱 파일이나 공유 자료에는 들어가지 않습니다. 팀원용 설정 링크를 카톡으로 보내면 팀원이 한 번 눌러 같은 카카오 지도를 씁니다(링크를 받은 사람만).

📘 키 받는 방법 (처음 한 번 · 약 5분)
  1. developers.kakao.com에 카카오 계정으로 로그인 → 내 애플리케이션 → 애플리케이션 추가하기 (앱 이름: 스마트 물길점검)
  2. 만든 앱 → 앱 설정 → 플랫폼 → Web 플랫폼 등록 → 사이트 도메인에 https://xhahr30-ops.github.io 입력·저장
  3. 제품 설정 → 카카오맵에서 사용 설정을 켜기(ON)
  4. 앱 키의 JavaScript 키를 복사해 위 칸에 붙여 넣기 → 저장하고 다시 열기
🔗 카카오 개발자 사이트 열기

PC에서 하는 게 편합니다. 같은 키로 카카오 지도·상수도 사업소 모으기·카톡 바로 보내기가 모두 됩니다.

REST API 키·Admin 키가 아니라 JavaScript 키입니다. 등록한 주소에서만 동작하므로 팀원에게 키를 알려 줘도 다른 곳에서 쓸 수 없습니다.

❓ 스마트 물길점검 사용법
🚀 처음 시작하기

스마트 물길점검은 현장점검·성과평가 일정을 지도와 목록으로 보고, 현장에서 점검표·사진·후속 조치를 기록하는 앱입니다.

  1. 위쪽(PC는 왼쪽 위) 회차에서 볼 회차를 고릅니다.
  2. 지도 위 날짜 칩을 누르면 그날 현장만 보입니다(‹ › 화살표로 넘김).
  3. 핀이나 목록의 현장을 누르면 주소·점검자·연락처와 단추(점검표·길안내·소식·QR)가 나옵니다.
  4. 휴대폰은 홈 화면에 설치하면 주소창 없이 앱처럼 열립니다(메뉴 → 앱으로 설치).
📱 화면 구성
  • PC: 왼쪽 칸(탭·검색·요약·목록) + 오른쪽 지도 + 오른쪽 세로 도구 막대. 왼쪽 칸은 오른쪽 가장자리나 ◀를 좌우로 끌어 폭 조절, ◀를 누르면 접기.
  • 휴대폰: 지도 위 검색창, 아래 정보 칸. 손잡이를 끝까지 내리면 한 줄로 접히고, 지도 오른쪽 ⌄로 완전히 숨김.
  • 탭: 목록 · 달력 · 점검자 · 위치 · 후속 조치 · 종합(점검자) · 소식
  • ≡ 메뉴: 현장 추가, 엑셀 불러오기·내보내기, 지도 설정, 오늘 점검, 달력 넣기, 글자 크기, 새로고침 등
🗺 지도 보기
  • 지도 설정(오른쪽 🗺 단추): 지도만 보기, 지도 끄기(목록만), 카카오 바탕지도, 경계, 지자체 색, 핀, 같은 곳 핀 묶기, 하루 동선, 이름표를 켜고 끔.
  • 지자체 색: 현장이 있는 시·군·구를 점 색(점검일·상태·점검자)으로 칠함. 오른쪽 아래 '점 색'으로 기준을 바꿈.
  • 숫자 핀: 한 사무실의 여러 팀. 누르면 펼쳐짐.
  • 하루 동선: 날짜를 고르면 점검팀별로 순서·구간 거리·시간을 보여 줌(직선거리 추정).
  • 가까운 현장 순(목록 위): 내 위치에서 가까운 순서로 정렬.
  • 내 담당만(목록 위): 내 이름을 한 번 고르면 내 현장만.
  • 위치 고치기: 현장 칸의 '지도에서 고치기'를 누르고 지도를 누름. '주소로 찾기'로 다시 찾기도 됨.
  • 카카오 지도(깃허브 판): 메뉴 → 카카오 지도 키. 관리자가 보낸 '설정 링크'를 한 번 누르면 자동 설정.
📋 점검표 쓰기 (점검자)
  1. 현장 칸의 점검표를 누릅니다.
  2. 팀평가: 항목마다 5~1점(해당없음)과 메모. 2점 이하는 후속 조치 등록.
  3. 이전 지적: 지난 회차 지적의 이행 상태와 확인 내용.
  4. 개별평가·면담: 점검자만 봄. 면담은 키보드 🎤 또는 칸 옆 🎤로 말로 입력.
  5. 결과: 결과 초안 만들기(Claude) → 고친 뒤 점검표 저장.
  6. 회차 이력: 같은 현장의 지난 회차 기록.

쓰는 중에 앱이 닫혀도 임시 저장되어 다시 열면 이어 쓸 수 있습니다.

📷 사진·후속 조치
  • 팀평가 항목·이전 지적·후속 조치 칸의 ＋ 사진으로 찍거나 앨범에서 고름(위치정보는 지우고 크기를 줄여 저장).
  • 후속 조치는 조치 전 / 조치 후 사진을 나란히. 현장팀이 조치 후 사진을 올리면 점검자가 '이행 확인'.
  • 점검표 사진 탭에서 설명 쓰기, 공개용에 넣기 고르기, 삭제(점검자).
  • 후속 조치 탭: 상태·기한·조치 내용은 현장팀도 고칠 수 있음.
  • 현장 QR(▦): 찍으면 그 현장의 후속 조치·사진 화면이 열림(깃허브 판 권장).
🔔 소식·공유
  • 소식 탭: 일정·상태·점검표 저장·후속 조치·사진 변경이 쌓이고, 새 소식은 빨간 숫자로 표시.
  • 고른 소식 보내기 / 오늘 소식 보내기: 휴대폰 공유창 → 카톡·문자. PC는 복사.
  • 현장 칸의 📤 소식: 그 현장 현재 상태 요약을 보냄.
  • 점수·개별평가·면담·이름·주소·연락처는 소식에 넣지 않습니다.
🖨 출력·파일
  • 점검결과 출력(종합 탭 · 결과 탭 · 내보내기): 현장별 결과표(A4, 많으면 2장) / 회차 종합 보고서, 공개용(점수 상세·면담·개별평가 제외) / 내부용.
  • 인쇄 창에서 PDF로 저장, 또는 한글(HWPX) 저장.
  • 엑셀 저장(주소·좌표 포함), 점검 결과 엑셀(종합 탭), 백업 파일(JSON) 만들기·불러오기.
  • 휴대폰 달력에 넣기: 지금 목록 일정을 .ics로(전날 9시 알림).
🗂 회차 관리
  • 새 회차 만들기(점검자): 회차 목록 → ➕. 현장·주소·인원을 복사하고, 2점 이하 항목·미이행 지적·끝나지 않은 후속 조치를 새 회차 '이전 지적'으로 넘김.
  • 최종 파일 받기·보관(내보내기): 최종 파일 4개를 받은 뒤 회차를 '보관'(기록은 지우지 않음). '보관 회차 보기'로 다시 봄.
  • 새 일정 엑셀을 불러오면 같은 팀명끼리 위치·이력이 이어집니다.
🔐 두 가지 판 · 권한
  • Claude 페이지(공유판): Claude 계정 로그인, 팀 전체가 같은 자료·사진·소식을 실시간으로 봄. 권한: 소유자 · 점검자(편집) · 현장팀(참여) · 보기. 바탕지도는 경계만.
  • 깃허브 판: 로그인 없음, 기록은 그 휴대폰 브라우저에만 저장. 이름 가운데는 *, 연락처 없음(공개판). 카카오 지도·설치 가능.
  • 새 판이 올라오면 위쪽에 '새 판이 올라왔습니다' → 🔄 새로고침.
⚙️ 편의 기능
  • 오늘 점검(메뉴): 오늘 현장 카드(길안내·점검표·연락처). 오늘 점검이 있으면 열 때 먼저 보임.
  • 달력 끌어 옮기기(PC 달력 탭): 현장을 다른 날짜로 끌어 놓기.
  • ↶ 되돌리기: 변경·삭제 직후 6초 동안 화면 아래 단추.
  • 가 글자 크기(메뉴): 보통·크게·아주 크게.
  • 다크 모드, 지도만 보기(발표·캡처용, Esc로 끝).
  • PC 단축키: / 검색 · ←→ 날짜 · F 지도만 보기 · T 오늘 점검 · Esc 닫기 · ? 사용법
❗ 알아 둘 점
  • 평가 점수·우수팀 후보·동선 거리는 참고용이며 확정이 아닙니다. 확정은 종합 검토 후 정합니다.
  • 자료에 없는 값은 '확인 필요'로 표시됩니다.
