②-1 상수관로 (SHP ZIP) 선택

  

   

   

  
  
  
관로를 올리면 수용가별 가장 가까운 관로 거리, 블록별 관로 연장·노후도를 계산합니다.

    PDF 인쇄에 관로 포함
   
📖 코드표 (재질·용도 코드 직접 지정)
    
재질·용도가 숫자 코드로 들어 있으면 한 줄에 코드=이름으로 적으세요. 예: MOP001=덕타일주철관(DCIP), SAA003=배수관. DCIP·SP·PE 같은 약어와 한글 재질명은 자동 인식합니다.

    
    

  

 


 

  
②-2 상수도 시설물 (SHP ZIP) 선택 · 밸브·소화전·유량계 등

  

   

   

  
  
  
정수장·배수지·가압장은 항상, 유량계는 줌 13, 소화전·밸브류는 줌 15, 제수밸브는 줌 16부터 지도에 보입니다. 밸브는 올려주신 나비 모양 심볼을 관로 방향으로 돌려 그리고(닫힌 제수밸브는 검은 심볼), 소화전·유량계·정수장·배수지·가압장·관말은 색 원 배지 아이콘으로 그립니다.

  

   
   
   

   

   
📖 시설 이름 대응표 (지물부호=이름)
    
한 줄에 SA207=이름처럼 적으면 지도·목록 이름이 바뀝니다. 파일명 레이어(예: 관말1=관말)도 됩니다.

☁️ 직원 공유 구글 시트·드라이브 · 실시간 
   
사진은 구글 드라이브에, 위치·접수번호·메모는 구글 시트에 모아 직원끼리 같은 사진을 봅니다. 서버는 처음 한 번만 만들면 됩니다 (📄 서버 코드·설치 방법 받기).

   
   

   

    
    

   

   

   

    🗺️ 기준자료 공유 소블록 경계 · 상수관로 · 상수도 시설물
    
관리자가 [⏫ 올리기]를 한 번 누르면, 공유 키를 넣은 다른 기기는 앱을 열 때 새 버전만 자동으로 받습니다 (같은 버전이면 받지 않음).

    
    

    

   

  

  

  

  
사진은 이 PC(브라우저)에만 저장됩니다. 같은 곳에서 찍은 사진은 위치 표시 1개로 묶이고, 누르면 넘겨 볼 수 있습니다.

  
  

  

  

  
묶음 기준: 정한 거리·시간 안이면 한 곳으로 묶고, 파일명이 비슷하면(예: 마산리누수1·2·3) 거리 2배까지 묶습니다. 위치 없는 사진은 파일명이 비슷하거나 10분 안에 찍은 사진의 묶음에 위치 추정으로 넣습니다. 휴대폰 GPS는 5~20m 오차가 있어 표시 위치는 참고용입니다.

  

 

 
주소와 SHP는 이 브라우저 안에서만 처리됩니다. 주소 검색 시 주소 문자열만 카카오(Apps Script 경유 시 구글 서버를 거쳐 카카오, 또는 OSM)로 전송됩니다. Apps Script 경유 방식은 카카오 키가 화면에 노출되지 않습니다.
