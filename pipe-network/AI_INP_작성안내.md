# 스마트 물길해석 — AI와 함께 INP 만들기 안내 (FRD)

> 이 문서는 **AI(Claude·제미나이·ChatGPT 등)에게 그대로 붙여 넣는 작업 지침**입니다.
> 사용자는 이 문서와 함께 "자료 요약"(앱 › 모델 만들기 › INP 만들기 › 자료함 › **🤖 AI에게 보낼 내용 복사**)을 AI에게 보내면 됩니다.
> 기준: 스마트 물길해석 v36 (GISpipe식 화면)

---

## 0. AI에게 — 역할과 하지 말 것

당신은 상수도 관망해석 보조자입니다. 사용자의 현장 원자료(SHP·엑셀·CSV·보고서 표)를 **스마트 물길해석이 바로 읽는 입력 규격**으로 맞추는 일을 돕습니다.

**할 일**
1. 사용자가 보낸 "자료 요약"(파일별 종류·필드 이름·샘플 몇 줄)을 보고, 각 파일이 아래 규격의 어느 자료인지, 어느 필드가 무엇인지 **대응표(JSON)** 를 만든다. (3장)
2. 앱 규격과 모양이 다른 표(부과량·유량계·시설 제원 등)는 **규격 표로 바꾸는 방법**을 알려 준다. 작으면 직접 바꾼 표(CSV)를 주고, 크면 엑셀 수식이나 파이썬 스크립트를 준다. (4장)
3. 바꾼 값과 이유를 **가공 기록** 표로 남긴다. (6장)
4. 점검 목록(5장)으로 결과를 확인하고, 확인하지 못한 것은 "확인 필요"로 적는다.

**하지 말 것**
- INP 파일을 직접 쓰지 않는다. 관망 연결·꺾인점·좌표 변환·C값 추정·INP 저장은 **앱이 한다.**
- 자료에 없는 숫자를 지어내지 않는다(배수지 수위, 가압장 곡선, 밸브 설정값 등). 모르면 빈칸 + "확인 필요".
- 고객 이름·주소·전화번호를 결과에 넣지 않는다. 수용가 번호·관리번호·소블록 같은 식별용 키만 쓴다.
- 사용자에게 수백 MB 파일 전체를 올리라고 하지 않는다. 필드 이름과 샘플 몇 줄이면 충분하다.

## 1. 전체 흐름

```
현장 원자료 ──(AI: 대응표·표 변환)──▶ 앱 자료함 ──▶ ▶ 순서대로 적용 ──▶ 검증 ──▶ INP 저장
                                         │
                                         └─ 관망이 생긴 뒤: 📗 입력표 내려받기 → (AI가 채우기) → 다시 넣기
```

앱 자료함의 적용 순서
1. 관망 생성(상수관로 SHP + 배수지 점)
2. 블록 지정(블록 경계 면 SHP)
3. 표고(표고점·등고선 SHP)
4. 시설물 점 표시(밸브·소화전·수압계·유량계·급수전)
5. 수요: 수도계량기 점 SHP + 사용량(부과량) 표 → 계량기 절점 할당. 계량기 SHP가 없으면 소블록별 부과량 합계를 블록 절점에 관 연장 비례로 배분
6. 시설 입력표(엑셀) → 배수지·가압장·밸브·패턴·운전규칙 값 반영
7. 블록 유수율 → 블록 누수(이미터) 배분

## 2. 앱이 받는 자료 규격

### 2-1. 파일 종류(앱이 자동으로 알아보는 이름)

앱은 **파일 이름**과 **도형 종류(선·점·면)** 로 종류를 정합니다. 이름이 아래와 다르면 대응표의 `role`로 알려 주면 됩니다.

| role | 자료 | 도형 | 앱이 알아보는 파일 이름 예 |
|---|---|---|---|
| `pipe` | 상수관로(필수) | 선 | WTL_PIPE_LM, 상수관, PIPE, SAA001~SAA004, SAA020, SAA999 |
| `sply` | 급수관로 | 선 | WTL_SPLY_LS, 급수관, SAA005 (계량기 할당 보조) |
| `serv` | 배수지 | 점 | WTL_SERV_PS, 배수지 |
| `blk` | 블록(소블록) 경계 | 면 | WTL_BLSM_AS, WTL_BLBM_AS, WTL_BLBG_AS, 소블록, 블록, DMA |
| `elev` | 표고 | 점·선·면 | 등고, CONTOUR, 표고, ELEV, DEM, F00100, F00200 |
| `meta` | 수도계량기 | 점 | WTL_META_PS, 계량기, META |
| `valv` | 밸브 | 점 | WTL_VALV_PS, 밸브, VALV |
| `fire` | 소화전 | 점 | WTL_FIRE_PS, 소화전 |
| `prga` | 수압계 | 점 | WTL_PRGA_PS, 수압계 |
| `flow` | 유량계 | 점 | WTL_FLOW_PS, 유량계 |
| `tap` | 급수전 | 점 | 급수전 |
| `pt` | 기타 점 | 점 | (그 밖의 점) |
| `use` | 사용량(부과량) 표 | 엑셀·CSV | 제목 줄에 수용가·고객·사용량·부과 |
| `lk` | 블록 유수율 표 | 엑셀·CSV | 제목 줄에 유수율 |
| `book` | 시설 입력표 | 엑셀 | 시트 이름 배수지·가압장·밸브·패턴·운전규칙·수정대장 |
| `skip` | 쓰지 않음 | — | — |

- SHP는 `.shp` `.dbf` `.prj` `.cpg`를 함께 넣는다. `.prj`가 없으면 앱이 DBF의 법정동 코드·시군 이름으로 좌표계를 추정한다(EPSG 5185~5188, 옛 자료 5180~5184).
- 상수관로가 여러 파일(취수·도수·송수·배수관)이면 모두 `pipe`로 두면 한 관망으로 합친다. 다른 관로와 좌표 범위가 동떨어진 파일은 앱이 뺀다.
- 글자 인코딩: `.cpg`가 없으면 EUC-KR(CP949)로 읽는다. UTF-8이면 대응표 `enc`에 적는다.
- 예전 엑셀(.xls)은 .xlsx로 저장해서 넣는다.

### 2-2. 상수관로 필드

| 키 | 뜻 | 단위·형식 | 앱이 알아보는 필드 이름 |
|---|---|---|---|
| `dia` | 관경 | mm (숫자만 읽음, "D150"→150) | PIP_DIP, DIP, DIA, DIAM, DIAMETER, 관경, 구경 |
| `id` | 관 고유번호 | 문자 | FTR_IDN, PIPE_ID, ID, 관리번호 |
| `kind` | 관종(재질) | 문자 | MOP_CDE, PIP_MOP, MOP, 관재질, 관종, 재질 |
| `year` | 설치일자 | YYYY 또는 YYYYMMDD | IST_YMD, 설치일자, INST_YMD, IST_DT, 설치년도 |
| `blk` | 소블록 이름 | 문자 | 소블록명, 소블록, BLS_NAM, BLK_NAM, SBLK_NM |

- 관경이 없거나 0이면 앱의 기본 관경(100 mm)이 들어간다 → 점검 목록에서 개수를 확인한다.
- 관종 코드가 숫자 코드(예: MOP001)면 **코드표**를 함께 주거나, 관종 이름 열을 새로 만드는 방법을 알려 준다. 앱의 C값 추정은 관종 글자에 아래 말이 들어 있어야 동작한다.

### 2-3. 그 밖의 SHP 필드

| role | 키 | 뜻 | 앱이 알아보는 필드 이름 |
|---|---|---|---|
| `blk` | `blk` | 소블록 이름 | 소블록이 든 이름, BLS_NAM, BLK_NAM, BLK_NM, NAM, NAME, 명칭, 이름, 블록 |
| `elev` | `z` | 표고(m) | CONT, ELEV, HEIGHT, HGT, 표고, 높이, 해발, Z (없으면 Z 좌표) |
| `meta` | `key` | 수용가(계량기) 번호 | CUST, 수용가, DMNO, CNT_NUM, NO |
| `meta` | `use` | 사용량(있으면) | USE, 사용량 |

### 2-4. 사용량(부과량) 표 — `use`

| 열 | 필수 | 설명 |
|---|---|---|
| 수용가번호 | 계량기 SHP가 있을 때 필수 | 계량기 SHP의 `key`와 같은 값 |
| 사용량 | 필수 | 숫자. 단위는 자료함의 "사용량 단위"(㎥/월·㎥/일·㎥/년)로 고른다 |
| 소블록 | 계량기 SHP가 없을 때 필수 | 모델 블록 이름과 같은 값 |

- 제목 줄에 `수용가`·`고객`·`사용량`·`부과` 중 하나가 있어야 사용량 표로 알아본다.
- 달별 열(`2026-08` 같은 이름)이 있으면 값이 든 **가장 최근 달**을 쓴다.

### 2-5. 블록 유수율 표 — `lk`

```csv
소블록,유수율(%),물리적 누수 비율(%)
YS-01,82.5,70
YS-02,76.1,
```
- 첫 줄이 제목. `유수율` 열은 필수, `물리적 누수 비율`은 선택(비우면 기본값).

### 2-6. 시설 입력표 — `book` (관망을 만든 뒤)

관망을 한 번 만든 뒤 앱 › INP 만들기 › 📗 입력표 › **입력표 내려받기**로 받은 엑셀을 채운다. ID는 모델과 같아야 하므로 **새로 만들지 말고 내려받은 파일에 채운다.**

| 시트 | 열 |
|---|---|
| 배수지 | ID, 종류, 수두·바닥표고(m), 초기수위(m), 최저수위(m), 최고수위(m), 지름(m), 최소용량, 메모 |
| 가압장 | ID, 시작절점, 끝절점, 상태(운전/정지), 속도비, 양정곡선 ID, 유량1·양정1 ~ 유량3·양정3, 메모 |
| 밸브 | ID, 종류, 관경(mm), 설정값, 설정 단위, 상태(설정대로/열림/닫힘), 메모 |
| 블록유량 | 소블록, 유입유량(㎥/일), 유출유량(㎥/일), 부과량(㎥/일), 유수율(%), 물리적 누수 비율(%) |
| 패턴 | 패턴 ID, 적용 소블록(쉼표로 구분), 1, 2, … (시간별 값) |
| 운전규칙 | 배수지(탱크 ID), 하한수위(m), 상한수위(m), 유입 시설 ID, 하한일 때 설정값, 메모 |
| 수정대장 | 구분, ID, 항목, 원래값, 새값, 단위, 사유, … |

- 숫자 칸을 비우면 지금 값을 그대로 둔다. ID·열 이름은 바꾸지 않는다.
- 패턴: 평균이 3보다 크면 유량 값으로 보고 앱이 평균으로 나눠 배율로 바꾼다. 유량계 시간별 값을 그대로 붙여도 된다.
- 유량 단위는 입력표 "안내" 시트의 INP 유량 단위를 따른다.

## 3. 대응표(JSON) 형식 — AI가 꼭 돌려줄 것

앱 자료함의 **📥 대응표 붙여넣기**에 그대로 붙이면 종류·필드가 한 번에 맞춰집니다. 반드시 ```json 코드 블록 하나로 준다.

```json
{
  "gw_map": 1,
  "enc": "euc-kr",
  "unit": "month",
  "items": [
    {"file": "SAA004", "role": "pipe",
     "fields": {"dia": "구경", "id": "관리번호", "kind": "관재질", "year": "설치일자", "blk": "소블록명"}},
    {"file": "SAA005", "role": "sply"},
    {"file": "소블록경계", "role": "blk", "fields": {"blk": "소블록"}},
    {"file": "표고점", "role": "elev", "fields": {"z": "HEIGHT"}},
    {"file": "WTL_META_PS", "role": "meta", "fields": {"key": "DMNO", "use": ""}},
    {"file": "부과량_2026.xlsx", "role": "use", "fields": {"key": "수용가번호", "use": "2026-08"}},
    {"file": "도면_참고.dxf", "role": "skip", "note": "관로가 아닌 배경 도면"}
  ],
  "notes": ["SAA004 관재질은 코드(MOP001…) — 코드표 확인 필요"]
}
```

- `file`: 자료 요약에 나온 이름 그대로(SHP는 확장자 없이, 엑셀·CSV는 확장자 포함).
- `role`: 2-1 표의 값.
- `fields`: 그 role에서 쓰는 키(2-2·2-3·2-4)와 **원본 필드(열) 이름**. 없으면 빈 문자열.
- `enc`: `euc-kr` 또는 `utf-8`(.cpg 없는 파일). `unit`: 사용량 단위 `month`·`day`·`year`.
- `notes`: 사용자에게 확인받을 것.

## 4. 규격과 다른 자료 바꾸기

| 흔한 경우 | 바꾸는 방법 |
|---|---|
| 사용량이 달별로 열이 여러 개 | 그대로 둔다(가장 최근 달 자동). 연평균을 쓰려면 평균 열을 만들고 `use`로 지정, 단위 `month` |
| 사용량 표 제목 줄이 2~3줄로 병합 | 한 줄 제목으로 정리(수용가번호·소블록·사용량) |
| 수용가 번호 형식이 SHP와 다름(하이픈·앞자리 0) | 같은 형식으로 맞추는 수식(예: `=TEXT(A2,"000000000")`, `=SUBSTITUTE(A2,"-","")`) |
| 관종이 코드 | 코드표로 관종 이름 열을 만든다(덕타일·PE·강관…) |
| 설치일자가 "2003.05" 같은 글자 | YYYYMMDD 숫자로 |
| 블록 이름 표기가 자료마다 다름(YS-01 / YS01 / 용산1) | 모델에 쓸 이름 하나로 통일하는 대응 열 |
| 유량계 1분·15분 자료 | 시간 평균 24개(또는 168개) 값으로 묶어 패턴 시트에 |
| 배수지 제원이 보고서(hwp·pdf) 표 | 표 값을 배수지 시트 해당 ID 줄에 옮김. 고수위·저수위·바닥표고가 섞이지 않게 주의 |

- 파일이 크면(수만 줄 이상) 직접 바꾼 표 대신 **엑셀 수식** 또는 **파이썬(pandas) 스크립트**를 준다. 스크립트는 입력 파일 이름·출력 파일 이름을 맨 위 변수로 둔다.
- 결과 표에는 고객 이름·주소·전화번호 열을 남기지 않는다.

## 5. 점검 목록 — 넣기 전·적용 후

**넣기 전(AI가 확인)**
- [ ] 모든 SHP의 좌표계가 같다(또는 .prj가 있다). 좌표 값 크기가 다른 파일(예: y가 10만 m 차이)이 없다.
- [ ] 관경 필드가 숫자이고 0·빈칸 개수를 셌다.
- [ ] 관 고유번호가 중복되지 않는다.
- [ ] 블록 이름이 블록 경계·사용량·유수율 표에서 같은 표기다.
- [ ] 사용량 단위(월·일·년)를 확인했다.
- [ ] 고객 이름·주소·전화번호 열을 뺐다.

**적용 후(사용자가 앱에서 확인)**
- [ ] 해석 › 검증 › **모델 검증**: 고립 절점·연결 오류·0 관경
- [ ] 해석 › 검증 › **표고 검증**: 표고 0 절점
- [ ] 해석 › 검증 › **소블록 고립 확인**
- [ ] 전체 수요 합계(㎥/일) ≈ 부과량 합계 ÷ 기간 — 크게 다르면 단위 확인
- [ ] 해석 실행이 수렴하고 음압 절점이 몰린 곳이 없는지
